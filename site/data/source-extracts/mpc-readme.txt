L183: # Multi-Processor Computing
L184: 
L185: Multi-Processor Computing (MPC) is a unified framework for High Performance Computing providing the most commonly used tools to implement scientific computing software. It includes a MPI 3.1 compliant implementation (with latter extensions), user-level threading engines supporting PThread specification and an OpenMP 3 runtime (with parts of 4.0 and 5.0) relying on them. MPC aims to be as modular as possible to allow users to use portions of its feature independently.

L201: ## Installation
L202: 
L203: ### Build from source
L204: #### Prerequisites
L205: 
L206: The following prerequisites are required to compile MPC:
L207: 
L208:   * The main archive file from the cite71†Downloads page L209:   * A C compiler (e.g., `gcc`)
L210:   * GNU Autotools
L211: 
L212: Other dependencies are automatically fetched by the `installmpc` helper script.
L213: #### Standard installation
L214: 
L215:   1. Unpack the main archive (tar format) and go to the top-level directory:
L216: 
L217:     $ tar xfz MPC_<version>.tar.gz
L218:     $ cd MPC_<version>
L219: 
L220: If your tar program does not accept the ’z’ option
L221: 
L222:     $ gunzip MPC_<version>.tar.gz
L223:     $ tar xf MPC_<version>.tar
L224: 
L225:   2. Choose an installation directory.
L226: 
L227: > [!WARNING] Using the default `/usr/local/` will overwrite legacy headers
L228: 
L229: Create a build directory
L230: 
L231:     $ mkdir BUILD
L232:   3. From the build directory, launch the installation script for MPC and its dependencies. Specifying the installation directory:
L233: 
L234:     $ <path/to/mpc>/installmpc --prefix=<path/to/installation/directory>
L235: 
L236: > [!NOTE] Use the flag `-jX` to specify a parallel installation. `X` should be a number and is the total amount of processes launched by Make. By default the `X` is the number of cores of the machine.
L237: ##### Common options for installmpc
L238: 
L239: The whole list of options can be retrieved using
L240: 
L241:     $ <path/to/mpc>/installmpc -h
L242: 
L243: The most commonly used are
L244:   * `--prefix` to specify the installation path
L245:   * `--enable-lsp` to run bear and produce a `compile_commands.json` file
L246:   * `--with-slurm` to activate the support of SLURM using PMIx
L247:   * `--with-hydra` to force Hydra support and deactivate SLURM support
L248:   * `--process-mode` to deactivate the privatization features and remove the dependency on cite109†MPC Compiler Additions L249:   * `--thread-based` to activate the privatization features
L250:   * `--enable-debug` to build in Debug mode
L251:   * `--disable-<module|dep>` to disable certain module or dependency provided features
L252:   * `--with-cuda` to enable CUDA support
L253:   * `--with-rocm` to enable ROCm/hip support
L254: #### Step by step installation
L255: 
L256: If you decide to install MPC without the helper script, you will need the following dependencies
L257: 
L258:   * HWLOC and OpenPA libraries installed
L259:   * Optionally a Fortran compiler if Fortran applications are to be used (e.g., `g77` or `gfortran`)
L260:   * Optionally SLURM
L261:   * Optionally libfabric and network libraries (portals, ibverbs...)
L262: MPC relies on the Autotools toolchain as a build system. The standard way to install it without the convenience script is the following
L263: 
L264:     $ ./autogen.sh
L265:     $ cd <BUILD> && <path/to/mpc>/configure --prefix=<path/to/installation/directory>
L266:     $ make install -j
L267: 
L268: The previous section described the default installation and configuration of MPC, but other alternatives are available. You can find out more details on the configuration by running:
L269: 
L270:     $ <path/to/mpc>/configure --help
L271: Specify the PMI based launcher to be used by MPC as follows:
L272: 
L273:   * `--with-hydra[=prefix]`: Compile MPC with the Hydra launcher (embedded in the MPC distribution). This option is enabled by default.
L274:   * `--with-slurm[=prefix]` Compile MPC with the SLURM launcher.
L275: 
L276: Specify external libraries used by MPC:
L277: 
L278:   * `--with-hwloc=prefix`: Specify the prefix of hwloc library
L279:   * `--with-openpa=prefix`: Specify the prefix of OpenPA library
L280:   * `--with-mpc-binutils=prefix`: Specify the prefix of the binutils
L281: Specify external libraries for gcc compilation:
L282: 
L283:   * `--with-gmp=prefix`: Specify the prefix of gmp library
L284:   * `--with-mpfr=prefix`: Specify the prefix of mpfr library
L285:   * `--with-mpc=prefix`: Specify the prefix of mpc multiprecision library
L286: 
L287: Specify external gcc and gdb:
L288: 
L289:   * `--with-mpc-gcc=prefix`: Specify the prefix of the gcc used by MPC
L290:   * `--with-mpc-gdb=prefix`: Specify the prefix of the gdb used by MPC
L291: ### Using Spack
L292: 
L293: cite110†Spack is a user-based package manager tailored to be used on supercomputers. Spack offers mechanisms to manage configurations and dependencies of the installed packages. For more information on how to use spack, see the cite111†spack documentation†spack.readthedocs.io .
L294: 
L295: MPC related projects have spack recipes that can be found cite112†here . You can install MPC through spack following those instructions
L296:   * Add the MPC repository to your spack installation
L297: 
L298:     $ spack repo add <mpc_repository>
L299: 
L300:   * See the configuration options
L301: 
L302:     $ spack info mpcframework
L303: 
L304:   * Install MPC
L305: 
L306:     $ spack install mpcframework
L307: 
L308: For more information concerning installation, please refer to cite113†INSTALL .
L309: ## Usage
L310: ### Sourcing MPC
L311: 
L312:   1. Source the mpcvars script (located at the root of the MPC installation directory) to update environment variables
L313: 
L314: For bash, sh and zsh
L315: 
L316:     $ source <path/to/installation/directory>/mpcvars.sh
L317: 
L318: For csh and tcsh
L319: 
L320:     $ source <path/to/installation/directory>/mpcvars.csh
L321: 
L322: Alternatively, if you installed MPC using spack, load the package
L323: 
L324:     $ spack load mpcframework
L325:   2. Check that everything went well at this point by running
L326: 
L327:     $ mpc_cc --help
L328:     $ mpcrun --help
L329: ### Compile using MPC
L330: #### Standard MPI compilers
L331: 
L332: MPC does provide standard MPI compilers such as `mpicc`, `mpic++`, `mpicxx`, `mpif77` and `mpif90`. Those compilers can be used as drop-in replacements for your application. They should behave in similar ways than those made available by other providers.
L333: 
L334: These compiler will call MPC but won't privarize by default (process-mode). If you'd like to port an existing build system relying on mpicc you may `export MPI_PRIV=1` which will turn on privatization in these wrappers.
L335: For example:
L336: 
L337:     $ MPI_PRIV=1 mpicc hello.c -o hello
L338:     # Will be strictly equivalent to
L339:     $ mpc_cc hello.c -o hello.c
L340: #### Custom MPC compilers
L341: 
L342: MPC provides custom compilers `mpc_cc`, `mpc_cxx` and `mpc_f77`. Those compilers allow the user to specify MPC-specific options. For instance, those compilers use the auto-privatization by default (if MPC was compiled with privatization support).
L343: 
L344: To compile MPC program from C sources, you may execute the `mpc_cc` compiler:
L345: 
L346:     $ mpc_cc hello_world.c -o hello_world
L347: This command uses the main default GCC (patched if privatization support enabled) to compile the code. If you want to use your favorite compiler instead (losing some features like OpenMP support and global-variable removal), you may use the mpc_cflags and mpc_ldflags commands:
L348: 
L349:     $ <path/to/installation/directory>/bin/mpc_cc -cc=${CC} hello_world.c -o hello_world
L350:     # Or, in a more explicit way
L351:     $ ${CC} hello_world.c -o hello_world $(mpc_cflags) $(mpc_ldflags)
L352: For more information about the options proposed by these compilers, please refer to the `--help` option
L353: 
L354:     $ mpc_(cc|cxx|f77) --help
L355: ### Launch using MPC
L356: 
L357: MPC provides multiple launcher wrappers to launch your application in a parallel and distributed environment.
L358: #### Standard MPI runners
L359: 
L360: The MPI standard `mpiexec` launcher and the convenience, community-adopted `mpirun` one are installed with MPC if the MPI support is enabled. They can be used a drop-in replacement to the ones provided by other implementation. To launch a simple program with 2 process
L361: 
L362:     $ mpirun -n 2 <your/application>
L363: 
L364: Important
L365: 
L366: MPC is not yet MPI 5.0 ABI compliant, Compiling and running a program with different MPI implementation is an undefined behavior
L367: Please make sure the program you try to run has been compiled using MPC compilers
L368: #### Custom MPC runner
L369: Alternatively, one can use the `mpcrun` scripts to benefit from all the features of MPC. This command allows the user to select the threading engine, the underlying network, the launcher, pass through options to the launcher... It is the preferred way to launch thread-based programs. Consider the following examples
L370: 
L371:     # Launching 4 tasks MPI within one UNIX process (using one core per task)
L372:     $ mpcrun -m=ethread_mxn -p=1 -n=4 -c=4 <your/application>
L373:     # Launching 4 tasks MPI each a UNIX processes
L374:     $ mpcrun -p=4 -n=4 <your/application>
L375: 
L376:     # Launching 4 tasks MPI within two UNIX processes with pthread and 4 threads by process (2 by task)
L377:     $ mpcrun -m=pthread -p=2 -n=4 -c=4 <your/application>
L378: The mpcrun script drives the launch of MPC programs with different types of parallelism. Another common usecase is to use the SLURM launcher. In such cases, it becomes handy to pass through options to SLURM
L379: 
L380:     # Launching 2 tasks on 2 nodes from the <partition> partition
L381:     $ mpcrun -l=srun -n=2 -N=2 --opt="--partition=<partition>" <your/application>
L382: The most common options used with `mpcrun` are
L383: 
L384:     -N=n, --node-nb=n               Total number of nodes
L385:     -p=n, --process-nb=n            Total number of UNIX processes
L386:     -n=n, --task-nb=n               Total number of tasks
L387:     -c=n, --cpu-nb=n                Number of cpus per UNIX process
L388: 
L389:     -m=n, --multithreading=n        Define multithreading mode
L390: 
L391:     -net=n, --net=, --network=n     Define Network mode
L392: 
L393:     -l=n, --launcher=n              Define launcher
L394:     --opt=<options>                 Launcher specific options
L395: 
L396:     --cuda                          Enable CUDA support
L397:     --rocm                          Enable ROCm support
L398: 
L399:     -v,-vv,-vvv,--verbose=n         Verbose mode (level 1 to 3)
L400: For more information about the options to launch an application using MPC, please refer to the `mpcrun` help
L401: 
L402:     $ mpcrun --help
L403: 
L404: Note
L405: 
L406: This command also provides the list of available multithreading and network modes

L433: 
L434:     # Use any browser of your liking
